# motion-ui — Provenance and Portfolio Notes

## Repository provenance

This repository mirrors / preserves the ZURB Motion UI library rather than documenting an original standalone product authored in this account. The current README, package structure, Travis configuration, Bower support and links point directly to the upstream ZURB project.

That distinction matters for portfolio use: third-party source should not be presented as personal engineering ownership.

## Portfolio decision

Accurate provenance prevents accidental overclaiming. It makes the rest of the GitHub profile more credible because original projects, design artifacts, experiments and third-party mirrors are clearly distinguished.
